# MilsimProbe：iOS 可行性测试原型

用途：在没有 Mac 的情况下，验证 iPhone 上 **网页地图 + 后台定位 + 低功耗蓝牙（FFF0）+ 语音播报** 能不能用。
不连接任何第三方服务器，也不包含原 App 的代码或素材。

## 一、云端编译（GitHub Actions）

1. 注册 GitHub 账号，新建一个仓库（建议**公开**仓库：macOS 编译不限免费时长；私有仓库的 macOS 分钟数按 10 倍扣，很快用完）。
2. 把本文件夹里的所有内容上传到仓库根目录，**包括隐藏的 `.github` 文件夹**。
   - 网页上传容易漏掉 `.github`，推荐装 GitHub Desktop 来提交。
3. 推送到 `main` 分支后会自动编译；也可以在仓库的 **Actions → Build unsigned IPA → Run workflow** 手动触发。
4. 大约 5~10 分钟后编译完成。点进这次运行，在页面底部 **Artifacts** 下载 `MilsimProbe-unsigned-ipa`，解压得到 `MilsimProbe-unsigned.ipa`。
5. 如果编译失败，把 Actions 里红色那一步的报错复制给我。

## 二、Windows 上签名安装（Sideloadly）

1. 安装 **iTunes 和 iCloud（从苹果官网下载的版本，不要用微软商店版）**，再安装 Sideloadly。
2. iPhone 用数据线连电脑，在手机上点“信任此电脑”。
3. 打开 Sideloadly，把 IPA 拖进去，填 Apple ID（建议用一个**小号**），点 Start。会要求输入密码和双重认证验证码。
4. 手机上：
   - **设置 → 通用 → VPN与设备管理** → 点你的 Apple ID → 信任。
   - iOS 16 及以上：**设置 → 隐私与安全性 → 开发者模式** → 打开，手机会重启。
5. 免费 Apple ID 签名 **7 天过期**，到期后用 Sideloadly 重新装一次即可。

## 三、测试清单

**定位（最重要）**
1. 定位面板：点“申请权限”，选允许；之后系统会询问是否改为“始终允许”，选始终。也可以去 设置 → 隐私 → 定位服务 → Milsim测试 → 始终 + 精确位置。
2. 点“开始定位”，打开“每分钟语音播报”。
3. 锁屏，揣兜里走 15~30 分钟。听每分钟有没有语音。
4. 回来看：“后台”更新次数是否一直在涨、“最长断档”是多少秒。日志里 `[GPS后台]` 就是锁屏时收到的位置。

**蓝牙（暂时没有模块时）**
- 点“启动蓝牙 → 扫描”，应该能扫到附近的耳机、手表等，说明扫描正常。
- **用另一台安卓手机模拟那个模块**：安卓上装 nRF Connect，在 “Configure GATT server” 里建一个服务 `FFF0`，加特征 `FFF1`（通知）、`FFF2`（写），然后在 Advertiser 里广播。iPhone 上打开“只显示 FFF0 设备”就能看到它，连接后可以互相收发数据。
- 连接后锁屏，在安卓端发通知数据，回来看日志里锁屏期间有没有收到。

**地图**
- 切换街道 / 卫星图层；点地图会打标记，日志里出现 `JS→原生 标记`，说明网页和原生之间的双向通信正常（原 App 的架构就是这样的）。

**导出日志**：日志面板 → 导出，可以存到“文件”或者发给自己，把结果发给我分析。

## 文件说明

- `project.yml`：XcodeGen 工程描述，云端会根据它生成 Xcode 工程
- `.github/workflows/build-ipa.yml`：云端编译脚本
- `Sources/`：Swift 源码（定位、蓝牙、语音、网页地图、界面）
- `Resources/map.html`：Leaflet 网页地图
